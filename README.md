# Personal Website v3.0

## Description

This is the third version of my personal website, designed to showcase my professional skills and projects, and to provide a platform for potential employers or collaborators to get to know me better.

For this iteration, I deliberately chose not to introduce new technologies, but instead to simplify my approach. The focus is now on minimalism approach, with a strong emphasis on typography and content clarity. The goal is to create a cleaner, more intentional user experience by reducing visual noise and prioritizing readability.

This version reflects a more mature design direction, where simplicity drives both aesthetics and usability. As always, I am already thinking ahead and considering a future v4.0 to continue refining the experience.

## Objectives

- Refine visual hierarchy and typography.
- Improve front-end development skills.
- Enhance interactivity and UI/UX design.
- Create a minimalist design.
- Establish an online presence.

## Installation & Usage

### Installation

1. Clone this repository:
    - Open your preferred Terminal.
    - Navigate to the directory where you want to clone the repository.
    - Run the following command:

```
git clone https://github.com/fchavonet/web-personal_website.git
```

2. Open the cloned repository.

3. Go to the v3.0 folder.

### Usage

1. Open the `index.html` file in your web browser.
