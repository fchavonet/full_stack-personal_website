Holberton School/ Dijon, France

Après un parcours professionnel atypique, j’ai intégré la Holberton School de Toulouse où j’ai suivi une formation intensive, puis j’y ai effectué une alternance en tant que Software Engineer. Avant même la fin de mon apprentissage, une opportunité en CDI m’a été proposée me permettant de poursuivre dans ce rôle sur le campus de Dijon. Ce parcours m’a permis de construire de solides bases techniques, tout en développant mes capacités d’adaptation, de résolution de problèmes et d’accompagnement. Aujourd’hui je poursuis mon évolution en contribuant à des projets concrets tout en aidant d’autres personnes à progresser.

Projets

Cowabunga

REACT / NODE.JS / SUPABASE

Cowabunga est une application web légère destinée au catalogage des cartes issues du jeu de cartes à collectionner Tortues Ninja de la marque UniVersus. L'idée m'est venue après un voyage à Londres, où un ami et moi avons découvert une nouvelle collection de cartes TMNT et avons commencé à acheter des paquets.

DBVA Cards API

NODE.JS / JAVASCRIPT

L'API Dragon Ball Visual Adventure Cards fournit des données structurées sur les cartes à collectionner publiées par Bandai dans les années 1990. Il s'agit d'une API open source, gratuite, conçue pour les développeurs, les collectionneurs et les passionnés qui souhaitent accéder facilement aux métadonnées des cartes.

Flask Shop Template

PYTHON / FLASK / BOOTSTRAP

Flask Shop est un template de site de commerce électronique entièrement personnalisable, développé en Python à l'aide de Flask pour le backend et Bootstrap pour la mise en page et le style. Un modèle basé sur une boutique en ligne de montres G-Shock est disponible sur le GitHub du projet.

GPT Stats

HTML / CSS / JAVASCRIPT

GPT Stats est une extension Chrome qui permet de suivre facilement votre utilisation de ChatGPT. Elle mesure automatiquement le temps que vous passez sur l'application, compte vos requêtes et affiche des statistiques d'utilisation utiles, le tout dans une interface contextuelle épurée et minimaliste.

G-Shock Database

PYTHON / CUSTOMTKINTER

G-Shock Database est une application conçue pour explorer l'univers des montres Casio G-Shock. Le développement a débuté par la création d'un robot d'extraction de données qui récupère des informations détaillées sur les modèles. Les données collectées sont ensuite présentées via une interface graphique.

Holberton Survivors

C# / UNITY

Holberton Survivors est un jeu d'action inspiré du célèbre titre Vampire Survivors. Développé par Yoann Rivet et moi-même, ce projet est notre travail de fin de première année à la Holberton School. N'ayant aucune expérience préalable sous Unity et en C#, nous sommes partis de zéro, consacrant un mois à la préparation et un autre au codage intensif, tout en apprenant ces technologies au fur et à mesure.

Men in Bricks

HTML / CSS / JAVASCRIPT

Page d'accueil officielle de Men in Bricks, un podcast français destiné aux passionnés de LEGO®. Il s'agit d'un site web statique et léger, conçu pour être rapide, réactif et visuellement attrayant.

Othello Game

HTML / CSS / JAVASCRIPT

Othello Game est une adaptation pour navigateur du jeu de société classique Othello (également connu sous le nom de Reversi). Les joueurs placent à tour de rôle des disques noirs ou blancs sur le plateau, pour retourner les disques de l'adversaire en les encerclant. La partie se poursuit jusqu'à ce qu'aucun des deux joueurs ne puisse plus effectuer de coup valide, et le joueur ayant le plus de disques sur le plateau emporte la partie.
